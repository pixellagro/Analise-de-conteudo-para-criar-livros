# Análise de conteúdo para criar livros

Estudo a fundo de cursos (vídeos do YouTube e PDFs) para montar um passo a passo de criação e publicação de livros de colorir infantis na Amazon KDP. O passo a passo vai da ideia e da pesquisa até a montagem dos arquivos, a publicação e a gestão do catálogo.

## O que tem aqui
- **`CLAUDE.md`:** as regras do projeto para o Claude Code.
- **`.claude/skills/estudar-conteudo/`:** o método de estudo, com:
  - transcrição inteira;
  - folhas de quadros com o tempo;
  - mapa do curso;
  - duas auditorias de cobertura;
  - o curso completo, regra por regra.
- **`docs/`:** o nosso estudo e o passo a passo. Só entram aqui com aprovação.
- **`refs/`:** material de terceiros (vídeo, legendas e PDFs). Fica só no computador e nunca é enviado para cá, por causa do `.gitignore`.

## Ferramentas usadas no computador
yt-dlp, whisper.cpp, ffmpeg, pdftotext e pypdf. Os caminhos estão na skill e valem para o computador onde o projeto foi montado.
